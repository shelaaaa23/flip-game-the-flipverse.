# FLIP GAME — The Flipverse
Starter PHP + MySQL untuk game kartu flip Matematika kelas VIII.

## Instalasi XAMPP
1. Ekstrak folder ini ke `C:/xampp/htdocs/`.
2. Jalankan Apache dan MySQL.
3. Import `database/schema.sql` melalui phpMyAdmin.
4. Sesuaikan `config/database.php` bila kredensial MySQL berbeda.
5. Buka `http://localhost/flip_game_the_flipverse/public/`.

Fitur awal: 12 kartu (jika bank soal mencukupi), soal acak per dunia, dua kesempatan, skor 100/60/0, bonus penyelesaian 50, dan pembahasan. Autentikasi, penyimpanan progres permanen, panel guru, serta analitik belum termasuk.
